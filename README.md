## 这是什么

“相相成长记录”是一款适合两个人共同使用的轻量成长记录应用。

它最初从早餐打卡出发，后来逐渐转变为更轻松的正向记录方式：不要求每天完美，也不强调不能中断。早餐、分享照片或视频、完成任务以及生活中其他值得鼓励的小事，都可以被记录、获得积分，并慢慢兑换成期待中的奖励。

> 不需要每天都完美，每一件值得记录的小事都算成长。

## 主要功能

- **成长记录**：记录早餐、分享、任务、沟通成就或自定义项目。
- **每周目标**：默认一周任意记录 3 天即可获得 1 枚相相玉，不要求连续。
- **月度奖励**：同一自然月完成 4 次周目标，再获得 1 枚相相玉。
- **累计里程碑**：早餐、分享和任务分别达到 10、30、60 次时获得阶段奖励。
- **双积分体系**：相相币用于日常小奖励，相相玉用于更稀有、更有期待感的奖励。
- **相相商店**：可以新增、编辑、删除商品，设置价格并标记心愿目标。
- **成长日历**：按月查看留下记录和获得奖励的日期。
- **成长回顾**：生成绘本风格的每日 PNG，可保存、分享或长按图片下载。
- **多设备同步**：两台手机登录同一个共同账号，即可同步账本、余额、商店和设置。
- **数据保护**：支持云端历史版本、回收站、本机恢复副本，以及 JSON 导入和导出。

## 当前成长规则

| 项目 | 默认奖励 | 说明 |
| --- | ---: | --- |
| 早餐记录 | 10 相相币 | 每天最多加分一次 |
| 分享照片或视频 | 3 相相币 | 默认每天最多 3 次 |
| 随机任务 | 10 相相币 | 次数可自行设置 |
| 沟通成就 | 20 相相币 | 次数可自行设置 |

每周记录目标可以在“记分 → 成长规则”中设置为任意 2～5 天。加分项目、分值、每日次数限制和商店商品也都可以自行调整。

## 在手机上使用

### iPhone

1. 使用 Safari 打开[应用页面](https://xiaoyang5022.github.io/xiangxiang-growth-record/)。
2. 点击底部的“分享”。
3. 选择“添加到主屏幕”。

### Android

1. 使用 Chrome 打开[应用页面](https://xiaoyang5022.github.io/xiangxiang-growth-record/)。
2. 打开浏览器菜单。
3. 选择“添加到主屏幕”或“安装应用”。

后续版本更新不需要重新安装。完全退出后再次打开，应用便会加载已发布的新版本。

## 云同步和数据安全

- 应用采用本地优先保存：临时断网时仍然可以继续记录，恢复网络后再同步。
- 在另一台手机上使用同一邮箱和密码登录，可以共享所有记录和设置。
- 同步遇到两份不同数据时会暂停覆盖，并让使用者选择保留本机版或云端版。
- 删除的记录、商品和项目会进入回收站。
- 云端保存历史版本，本机也会保留最近的恢复副本。
- 建议定期使用“数据保护与恢复 → 导出备份”，将 JSON 文件保存在手机文件或个人网盘中。

清除浏览器的网站数据、使用无痕模式或更换浏览器，都可能移除该设备上的本机副本；已经成功同步到云端的数据不受影响。

## PNG 成长回顾

手机端点击“保存 / 分享 PNG”后，可以在系统菜单中选择：

- 存储到照片；
- 存储到文件；
- 发送给好友或其他应用。

如果系统分享菜单不可用，可以点击“图片预览”，然后长按图片保存。

## 技术说明

这是一个无需构建步骤的静态 Web 应用：

- 原生 HTML、CSS 和 JavaScript；
- Canvas 生成每日成长回顾；
- Web App Manifest 提供主屏幕图标和安装体验；
- Supabase 提供登录、云同步、实时更新及历史版本能力；
- GitHub Pages 负责托管和发布。

## 设计原则

这个项目不希望把陪伴变成考核，也不希望因为偶尔中断就否定之前的努力。积分和奖励只是表达在意的一种方式，真正重要的是让每一次认真生活、主动分享和彼此沟通都有被看见的机会。
